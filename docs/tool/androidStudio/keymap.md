# Android Studio 快捷键

Option=Alt
## 定位到当前打开文件的位置

- **Windows / Linux**: `Alt + F1, 1`
- **macOS**: `Alt + F1, 1`
## 搜索文件名

- **Windows / Linux**: `Ctrl + Shift + N`
- **macOS**: `Cmd + Shift + O`

## 使用全局搜索快捷键

- **Windows / Linux**: `Ctrl + Shift + F`
- **macOS**: `Cmd + Shift + F`


## 复制当前行（或选中的多行）的快捷键如下：

- **Windows / Linux**: `Ctrl + D`
- **macOS**: `Cmd + D`

## 在 Android Studio 中，格式化代码的默认快捷键取决于你的操作系统：
- Windows / Linux: Ctrl + Alt + L
- macOS: Cmd + Alt + L (⌘ + ⌥ + L)
补充技巧：格式化特定代码块：先选中你想格式化的代码，然后按下上述快捷键。

## 优化导入（Remove unused imports）：
- Windows/Linux: Ctrl + Alt + O
- macOS: Ctrl(Cmd) + Alt + O (注意是 Control 不是 Cmd)
重新排列代码（Reorder methods/fields）：通常在格式化设置中勾选 "Rearrange code" 后，使用格式化快捷键会一并执行。

## 返回上一个光标浏览位置（即导航历史回退）的快捷键如下：

- Windows/Linux	
    Ctrl + Alt + ← (左箭头)	
    Ctrl + Alt + → (右箭头)
- macOS	
    ⌘ (Cmd) + [	
    ⌘ (Cmd) + ]
